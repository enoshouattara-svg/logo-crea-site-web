# Logo : création de sites web

Logo de l'activité de création de sites web, en **PNG** et en **SVG** (vectoriel, pour l'impression).

- versions **horizontale** et **verticale**, en or ou en noir, sur fond transparent ou coloré ;
- **monogramme** seul, en or ou en noir ;
- **photo de profil TikTok**.

Utilise les fichiers `svg/` pour l'impression ou les grands formats, et `png/` pour les réseaux sociaux.
